README.md-213-
README.md-214-- **Work-stealing traversal.** Workers act both as directory scanners and as file
README.md-215-  searchers, and traverse depth-first per branch. Output is streamed as results
README.md:216:  arrive, unless `--sort` is given. `--sort` keeps the GNU grep order through
README.md-217-  ordered tickets, and a file with no match releases its ticket with one atomic
README.md-218-  write instead of being buffered.
README.md-219-- **Direct directory reads.** On Linux, `getdents64` feeds 32 KB batches through
README.md-220-  a VFS layer (`src/vfs.zig`), with no `readdir()` or per-entry `stat()`. Ignore
README.md-221-  rules prune branches before `openat`/`statx`. Besides `.gitignore` and
README.md-222-  `.dataignore`, found by walking up to the repository root, a built-in list
README.md-223-  skips `.git`, `node_modules`, `target`, `.zig-cache` and `.venv`.
README.md-224-  `--no-default-ignore` disables that list.
